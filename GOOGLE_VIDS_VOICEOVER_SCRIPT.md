## 🎯 USAGE INSTRUCTIONS FOR GOOGLE VIDS:

### Step-by-Step:

1. **Open Google Vids**
   - Go to vids.google.com
   - Create new project or open existing demo project

2. **Add Voiceover**
   - Click on "Voiceover" or "Audio" option
   - Select "AI Voiceover" or "Text-to-Speech"

3. **Select Voice**
   - Choose: **Male voice**
   - Style: **Professional** or **Narration**
   - Recommended voices in Google Vids:
     - "Studio - Deep"
     - "Wavenet - Male 1" (if available)
     - Any professional male voice option

4. **Paste Script**
   - Copy the ENTIRE script above (everything between the ``` marks)
   - Paste into Google Vids voiceover text box
   - Review to ensure all text copied correctly

5. **Adjust Settings**
   - Speed: **1.0x** (normal pace)
   - Pitch: **-1 or -2** (slightly deeper, more professional)
   - Volume: **Normal** or **+1**

6. **Generate**
   - Click "Generate" or "Create Voiceover"
   - Wait for processing (may take 1-2 minutes)
   - Preview the audio

7. **Sync to Video**
   - Align voiceover with your video timeline
   - Adjust timing if needed (add pauses in script if it's too fast)
   - Ensure narration matches visual actions

8. **Fine-tune (Optional)**
   - If some parts are too fast, add more periods or commas
   - If you need longer pauses, add: (pause) in the script
   - Regenerate specific sections if needed

9. **Export**
   - Once satisfied, export your complete demo video
   - Format: MP4, 1080p recommended

### If Narration is Too Fast:

```

```

### If You Want Longer Pauses:
Add "(pause)" where needed:

```

```

### If You Want More Emphasis:
Capitalize key words (Google Vids may emphasize them):

```
PromptOps provides AI-POWERED insights at every step.
```

### If You Want Slower Pace:
In Google Vids settings, set speed to **0.9x** or **0.85x**
