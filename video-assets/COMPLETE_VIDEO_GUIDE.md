## 📋 Complete Step-by-Step (Option 2 - Recommended)

### PHASE 1: Generate Scene Images (30 minutes)

#### Using Midjourney (Best Quality):
1. Join Discord: https://discord.gg/midjourney
2. Go to any #general channel
3. Type `/imagine` command
4. Paste prompt from `mockup-descriptions.md` Scene 1
5. Wait ~1 minute for generation
6. Click image to upscale → Download
7. Repeat for all 12 scenes

#### Using DALL-E (via ChatGPT):
1. Go to https://chat.openai.com (need ChatGPT Plus)
2. Copy prompt from `mockup-descriptions.md` Scene 1
3. Ask: "Generate this image: [paste prompt]"
4. Download image
5. Repeat for all 12 scenes

#### Using Canva (Alternative):
1. Follow `CANVA_TEMPLATES_GUIDE.md`
2. Create mockups directly in Canva
3. No need for separate images

---

### PHASE 2: Generate Voiceover (5 minutes)

#### Using ElevenLabs (Best Quality - Free Tier Available):
1. Go to https://elevenlabs.io
2. Sign up for free account
3. Click "Speech Synthesis"
4. Choose voice: **"Josh"** (professional male)
5. Copy entire script from `VOICEOVER_SCRIPT.txt`
6. Remove timing markers like [SCENE 1]
7. Paste clean script
8. Click "Generate"
9. Download MP3

**Result:** `promptops_voiceover.mp3` (~3 minutes)

---

### PHASE 3: Assemble Video (60 minutes)

#### Using DaVinci Resolve (Free, Professional):

**Download & Install:**
1. Go to https://www.blackmagicdesign.com/products/davinciresolve/
2. Download free version
3. Install (requires registration)

**Create Project:**
1. Open DaVinci Resolve
2. Click "New Project" → Name: "PromptOps Hackathon"
3. Set timeline to 1920x1080, 30fps

**Import Assets:**
1. Click "Media" tab (bottom left)
2. Import all 12 scene images
3. Import voiceover MP3
4. Import background music (optional)

**Build Timeline:**
1. Click "Edit" tab
2. Drag Scene 1 image to timeline
3. Set duration: 25 seconds (right-click → Change Clip Duration)
4. Repeat for all 12 scenes with proper durations:
   - Scene 1: 25s
   - Scene 2: 15s
   - Scene 3: 70s (split into 3 images if needed)
   - Scene 4: 30s
   - Scene 5: 30s
   - Scene 6: 8s

**Add Voiceover:**
1. Drag `promptops_voiceover.mp3` to Audio Track 1
2. Align with start of timeline
3. Sync voiceover timing with image changes

**Add Text Overlays:**
1. Click "Effects" → "Titles" → "Text"
2. Drag text to Video Track 2 (above images)
3. Edit text in viewer (see `mockup-descriptions.md` for each scene's text)
4. Adjust font: Inter or Montserrat, Bold, 48pt+ size
5. Color: White with slight blue glow

**Add Transitions:**
1. Click "Effects" → "Video Transitions" → "Dissolve"
2. Drag between clips
3. Duration: 0.5 seconds

**Add Background Music (Optional):**
1. Download music from YouTube Audio Library (free)
2. Search: "technology inspiring" or "tech innovation"
3. Import to timeline on Audio Track 2
4. Lower volume to -20dB (don't overpower voiceover)
5. Fade in/out at start/end

**Export Video:**
1. Click "Deliver" tab
2. Format: MP4
3. Codec: H.264
4. Resolution: 1920x1080
5. Quality: High
6. Filename: `PromptOps_Hackathon_Video.mp4`
7. Click "Add to Render Queue"
8. Click "Render All"
9. Wait ~5 minutes for export

**Result:** Final video ready for submission! 🎉

## 📞 Troubleshooting

### "Midjourney won't let me generate images"
→ Use DALL-E (ChatGPT Plus) or create mockups in Canva instead

### "DaVinci Resolve is too complicated"
→ Use Canva Video option instead (easier, all-in-one)

### "I don't have time for this"
→ Hire a freelancer on Fiverr ($50-100, 2-3 day turnaround)

### "Video is over 3 minutes"
→ Trim scenes slightly: Cut 2-3 seconds from longer scenes

### "Voiceover sounds robotic"
→ Try ElevenLabs (more natural) or record yourself

### "File size is too large"
→ Re-export at lower bitrate: 8-10 Mbps instead of 15-20 Mbps
