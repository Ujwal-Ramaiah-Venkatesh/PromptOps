# Video Generation Prompt: PromptOps Problem Statement

## Video Objective
Create a compelling 60-90 second explainer video that showcases the critical problems PromptOps solves for DevOps teams and organizations managing cloud infrastructure.

---

## Video Prompt for AI Video Generators (Runway, Synthesia, Pictory, etc.)

### Master Prompt:

```
Create a professional explainer video (60-90 seconds) showing the problems modern DevOps teams face:

SCENE 1 (0-15s): "The Cloud Complexity Crisis"
- Visual: Overwhelmed DevOps engineer at computer with multiple monitors showing AWS, Azure, GCP dashboards
- Text overlay: "Modern organizations manage 1,000+ cloud resources across multiple clouds"
- Show: Chaotic dashboard with red alerts, rising cost graphs, security warnings
- Mood: Stressful, overwhelming, fast-paced

SCENE 2 (15-30s): "The Cost of Manual Operations"
- Visual: Split screen showing:
  LEFT: Engineer manually checking resources at 2 AM (on-call stress)
  RIGHT: Rising cost meter: "$5,600 per minute during downtime"
- Text overlays:
  - "80% of time spent FIREFIGHTING, not innovating"
  - "6-8 hours to detect issues"
  - "4-6 hours to resolve incidents"
- Show: Calendar with highlighted on-call shifts, burnt out team

SCENE 3 (30-45s): "Hidden Waste & Security Risks"
- Visual: Money literally burning/disappearing
- Text overlays:
  - "35-40% of cloud spend WASTED"
  - "280 days to detect security breaches"
  - "70% from simple misconfigurations"
- Show: Untagged resources, idle instances running 24/7, open S3 buckets

SCENE 4 (45-60s): "The Real Business Impact"
- Visual: E-commerce Black Friday example as animated sequence:
  - 6:00 PM: Traffic spike graph going vertical
  - 6:45 PM: Website with error page/loading spinner
  - 8:30 PM: Site restored but damage done
- Text overlay: "2.5 hours downtime = $840,000 LOST"
- Subtitle: "This was 100% PREVENTABLE"

SCENE 5 (60-75s): "Multi-Cloud Chaos"
- Visual: Three separate silos labeled AWS, Azure, GCP with no connections
- Show: Different tools, interfaces, costs flying everywhere
- Text overlay: "No unified view. No predictive intelligence. Just reactive chaos."

SCENE 6 (75-90s): "The Question"
- Visual: Camera zooms out to show the full picture of chaos
- Text overlay (bold): "What if your cloud operations were..."
- Fade to black with text appearing word by word:
  - "PROACTIVE?"
  - "PREDICTIVE?"
  - "AUTOMATED?"
- End frame: "PromptOps: AI-Powered Cloud Operations" + logo

STYLE GUIDE:
- Color scheme: Dark blues, reds (for problems), burning orange (for waste)
- Font: Modern, clean sans-serif (Montserrat, Inter, or similar)
- Music: Tense, building tension, then hopeful at end
- Pace: Fast-moving for problems, slight pause before final question
- Tone: Professional but urgent, documentary-style

KEY VISUAL ELEMENTS:
- Animated graphs showing exponential growth (costs, alerts, incidents)
- Clock ticking for downtime scenes
- Money/dollar bills burning or flying away
- Red alert notifications stacking up
- Stressed facial expressions of engineers
- Multiple browser tabs/windows showing different cloud consoles
```

## Video Specifications

### Technical Requirements:
- **Duration:** 60-90 seconds
- **Format:** 16:9 (1920x1080) for YouTube/LinkedIn
- **Alternative:** 9:16 (1080x1920) for TikTok/Instagram Reels/YouTube Shorts
- **Frame Rate:** 30fps minimum
- **Audio:** Professional voiceover + background music
- **Captions:** Burned-in subtitles (80% of social video watched without sound)

### Visual Assets Needed:
1. Stock footage of stressed DevOps engineers
2. Screen recordings of AWS/Azure/GCP dashboards
3. Animated cost charts and graphs
4. Alert notification animations
5. Money/cost waste visualizations
6. Clock/timer graphics
7. Security warning icons
8. PromptOps logo and brand assets

### Color Psychology:
- **Red/Orange:** Problems, urgency, costs, alerts
- **Dark Blue:** Professionalism, tech, current state
- **Yellow/Gold:** Money waste, attention
- **Green:** (Save for solution video) Success, savings, fixes

## Platform-Specific Adaptations

### For AI Video Generators (Synthesia, HeyGen, D-ID):
```
Create an avatar-based explainer video with a professional presenter in business casual attire. Use split-screen to show the presenter on left (1/3 screen) and animated visualizations on right (2/3 screen). 

Avatar should display concerned/serious expression during problem sections, then hopeful expression during the final question section.

Background: Modern office or dark tech-themed backdrop.
```

### For Animation Tools (Vyond, Animaker, Powtoon):
```
Create a 2D animated explainer using:
- Character: DevOps engineer character showing stress and exhaustion
- Icons: Cloud symbols, server racks, alert bells, money stacks
- Charts: Animated line graphs showing costs rising, pie charts showing waste
- Scenes: Transition with slide or fade effects every 15 seconds
- Style: Modern flat design with slight shadows for depth
```

### For Screen Recording + Motion Graphics (After Effects, DaVinci Resolve):
```
Combine screen recordings of actual cloud dashboards with motion graphics overlays:
- Use real AWS/Azure/GCP console footage (blur sensitive info)
- Add animated callouts highlighting problems
- Kinetic typography for key statistics
- Smooth transitions between scenes (0.5s cross dissolve)
- Lower thirds with key metrics appearing on beat
```

## Voiceover Direction

**Tone:** Professional, authoritative, slightly urgent

**Pacing:** 
- Fast during problem enumeration (builds urgency)
- Slow and deliberate for the "$840,000 lost" line (let it sink in)
- Hopeful and confident for closing questions

**Emphasis Words:**
- DROWNING
- AFTER (they happen)
- WASTED
- 280 DAYS
- $840,000
- PREVENTABLE
- PROACTIVE
- INTELLIGENT

**Gender:** Either male or female works - prioritize clear enunciation and authoritative tone

**Accent:** Neutral American or British English

## Quick Start with AI Tools

### Using Synthesia:
1. Paste the script into Synthesia
2. Choose "Professional Male/Female" avatar
3. Select "Corporate Modern" template
4. Add screen recordings as B-roll
5. Export in 1080p

### Using Pictory:
1. Upload script as article/text
2. Let AI suggest scene breaks
3. Replace AI-selected stock footage with cloud dashboard recordings
4. Adjust timing to 2-3 seconds per scene
5. Add background music from library

### Using Runway Gen-2:
1. Generate each scene separately with detailed prompts
2. Use "motion brush" for animated elements
3. Combine scenes in editing software
4. Add voiceover and music
