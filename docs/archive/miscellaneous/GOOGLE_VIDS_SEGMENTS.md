### Step 5: Add Smooth Transitions

**Between ALL clips, add:**
- **Transition type:** Cross-dissolve (fade)
- **Duration:** 0.3 seconds (300ms)
- **Placement:** Overlap end of Clip N with start of Clip N+1

**How to add in each editor:**

**CapCut:**
1. Click between two clips on timeline
2. Click "Transition" in toolbar
3. Select "Dissolve" or "Fade"
4. Set duration to 0.3s

**DaVinci Resolve:**
1. Go to "Edit" page
2. Drag "Cross Dissolve" from Effects Library
3. Drop between clips
4. Adjust handles to 15 frames (0.5s) or shorter

**Clipchamp:**
1. Click "+" between clips
2. Select "Fade" transition
3. Adjust duration slider to 0.3s

### Step 6: Audio Mixing for Sync

**DaVinci Resolve Audio Mixing:**

**Key Rule:** Voiceover must ALWAYS be clearly audible over music

## 📝 TEXT CLARITY GUIDELINES - READ BEFORE GENERATING

### Why Text Might Be Unclear:
1. ❌ Font too small (below 48pt)
2. ❌ No contrast (white text on light background)
3. ❌ No shadow/outline on text
4. ❌ Text appears too briefly (under 2 seconds)
5. ❌ Complex fancy fonts instead of simple sans-serif
6. ❌ Low video export quality/compression
7. ❌ Text in screen corners or edges (gets cut off)

### How to Ensure CLEAR Text:

#### In Google Vids Prompt:
Always specify in your prompt:
```
TEXT REQUIREMENTS:
- Font size: MINIMUM 60pt, preferably 72-100pt
- Font type: Bold sans-serif (Arial, Helvetica, Roboto)
- Color: White text with 3px black outline/shadow
- Background: Semi-transparent black box behind text (rgba(0,0,0,0.7))
- Position: Center screen or lower third
- Duration: Display each text element for MINIMUM 3 seconds
- High contrast: Ensure text stands out from background
```

#### In Video Editor (Post-Production):
If text is still unclear after generation:

**CapCut:**
1. Select clip → Right panel → "Text"
2. Add new text overlay with same words
3. Font: Arial Black or Roboto Bold
4. Size: 80-120
5. Color: White
6. Add "Stroke" effect: Black, 3-5px
7. Add shadow: Black, 50% opacity
8. Duration: 3+ seconds

**DaVinci Resolve:**
1. Effects → Titles → "Lower Third"
2. Customize font to Arial Bold, size 100
3. Add drop shadow in Inspector panel
4. Add background box (black, 70% opacity)
5. Export at high bitrate (15+ Mbps)

**Clipchamp:**
1. Text → Add text
2. Font: Arial Black
3. Size: Large or Extra Large
4. Text effects → Outline (black, thick)
5. Background → Add shape behind text

### Best Practices for Maximum Readability:

✅ **DO:**
- Use LARGE font sizes (72pt minimum)
- Use BOLD weights (Bold or Extra Bold)
- Use simple sans-serif fonts (Arial, Helvetica, Roboto)
- Add black outline or shadow to ALL text
- Place text on semi-transparent dark background
- Display text for 3+ seconds minimum
- Use high contrast (white on dark, or dark on white)
- Export at 1080p with high bitrate (12+ Mbps)
- Test on mobile phone before finalizing

❌ **DON'T:**
- Use small fonts (below 48pt)
- Use fancy script or decorative fonts
- Put white text on light backgrounds
- Display text for less than 2 seconds
- Place text in corners or edges
- Export at low quality/bitrate
- Use low contrast colors

### Text Hierarchy for Each Clip:

**Primary Text** (Most important - numbers, key stats):
- Size: 80-100pt
- Weight: Extra Bold
- Color: Bright (white or orange #fb923c)
- Shadow: 4px black shadow
- Duration: 3-4 seconds

**Secondary Text** (Supporting information):
- Size: 60-72pt
- Weight: Bold
- Color: White
- Shadow: 3px black shadow
- Duration: 2-3 seconds

**Tertiary Text** (Additional details):
- Size: 48-60pt
- Weight: Medium Bold
- Color: Light gray or white
- Shadow: 2px black shadow
- Duration: 2 seconds

### Testing Text Clarity:

After generating each clip:
1. ✅ Watch on phone (smallest screen)
2. ✅ Pause at text moments - can you read every letter?
3. ✅ Check from 6 feet away - still readable?
4. ✅ Watch with low brightness - text still visible?
5. ✅ Ask someone unfamiliar to read text - can they?

If answer is NO to any, regenerate with LARGER text or add text overlay in editor.
